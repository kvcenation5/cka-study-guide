# Mock Tests

This section contains practice tests for the Certified Kubernetes Administrator (CKA) exam.

## Available Mock Tests

### [Mock Test 1](mock-test-1.md)
20 questions covering fundamental CKA topics including Pods, Deployments, Services, ConfigMaps, Secrets, RBAC, NetworkPolicies, and basic troubleshooting.

### [Mock Test 2](mock-test-2.md)
16 advanced practical scenarios covering ServiceAccounts with ClusterRoles, ConfigMaps with Deployment environment variables, PriorityClasses, NetworkPolicies, StorageClasses, Sidecar containers, Ingress, HPA, Gateway API, Helm, CSR/RBAC, DNS troubleshooting, Static Pods, and extended CSR scenarios.

### [Mock Test 3](mock-test-3.md)
22 comprehensive questions covering:
- System configuration (sysctl parameters)
- Storage (PV, PVC, binding troubleshooting)
- Resource management (ResourceQuotas, LimitRanges)
- Scheduling (Pod Affinity, Anti-Affinity, Node Selectors, Taints/Tolerations)
- Cluster administration (etcd backup/restore, Kubelet troubleshooting, cluster upgrades)
- Workloads (Init Containers, Deployments, CronJobs)
- Advanced networking (HPA with custom metrics, HTTPRoute traffic splitting)
- Troubleshooting (PVC/PV binding, kubeconfig issues)
- Helm operations
- Cluster configuration (pod CIDR extraction)
